# NOIR VAULT v7

Plataforma de streaming premium en desarrollo.

## Estado inicial
Este repositorio es la base del proyecto NOIR VAULT v7. La primera entrega incluirá la experiencia web, catálogo y estructura técnica para integrar autenticación, suscripciones y reproducción de contenido con licencia.

## Tecnologías previstas
- Next.js y React
- Supabase para autenticación y base de datos
- Stripe para suscripciones
- Proveedor de vídeo con derechos de distribución

## Seguridad
No guardar claves secretas en el repositorio. Configurarlas como variables de entorno en el servicio de despliegue.

## Aviso
Esta versión inicial no ofrece todavía cuentas reales, cobros ni reproducción de vídeo.
